How a graph was recognised

Each drawing arrives as an inline <svg> whose aria-label names it in a fixed house style. That label is what the classification reads, so a question counts as having a graph only where College Board's own wording says it does:

Bar, line, scatter, histogram, dot plot, box plot, circle graph, coordinate-plane graphs and number lines count as graphs. Geometric figures and data tables are recorded separately — a table is not a graph, and neither is a triangle.
